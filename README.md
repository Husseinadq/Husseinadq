## About

Backend engineer with 4+ years building web systems, mostly in PHP/Laravel, now working increasingly in Python and FastAPI. I like shipping small, useful products — especially Arabic-first tools for merchants and businesses in the MENA region.

I run my own infrastructure: Ubuntu is my daily driver, and I manage VPS deployments alongside GCP and AWS. Long-term, I'm interested in AI/LLM engineering and Arabic NLP.
